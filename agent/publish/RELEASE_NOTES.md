# 遥信逻辑分析仪：v15装置固件与网页实验预览版

提供独立8102网页服务、16路数字波形、原始样本游标、边沿触发、缩放/平移、文件回放，以及CPU3独立A7采集和当前值监视源码。最多1秒/百万点/2MB，满深度保留首段；现有8098/8099/6011保持独立。

下载内容：

- `open_logic-device-v15-20261016.tar`：实际部署v15的ELF、匹配内核模块、服务和启停脚本；未压缩，使用 `tar -xf`。
- `open_logic-device-v15-source.tar.gz`：与v15构建清单匹配的源码。
- `logic16.elf`、`logic16_access.ko`：可单独核对的CPU3固件与Linux模块。
- `open_logic-source-20261016.zip`：本次Git版本完整快照，包含当前源码、原理图、参考代码与选定验收证据。
- `SHA256SUMS`：上述下载文件的SHA256；运行包内部也有四文件校验清单。

当前Git源码比v15多三处诊断/测试修正，未更新正在运行的实机。固件要求T153/TQ153、内核 `5.10.198-rt97-rtmpu-periph3-a7-rt`、匹配的CPU3 RemoteProc和预留内存布局。此处的固件镜像是CPU3 ELF；本次未取得本项目整机刷写IMG，未打包其他板卡的系统镜像或SDK。

离线验证：Node19/19、Linux服务5/5、C板级/状态机ASan/UBSan通过；浏览器图案36/36、软件装置源19/19、真实监视12/12，详见仓库验收记录。

**本版仅作实验预览。** 三路实际接点差异仍未在软件中读到，实物读数全0xFFFF；真实监视验收只证明网页与装置返回值一致。1MHz既有成功段也有超期停采段，尚未证明长期稳定；速率指读锁存器，不代表光耦带宽。485/CAN解码、90ns硬件直接触发RD及断电自动启动未完成。

本次仅发布与离线验证，没有停止当前网页/装置、没有新建现场采集，也没有部署新的固件。
