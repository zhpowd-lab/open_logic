# 遥信逻辑分析仪

GitHub仓库：[zhpowd-lab/open_logic](https://github.com/zhpowd-lab/open_logic)。源码、v15固件ELF、运行包及原理图的交付范围、版本对应和校验方法见 [GitHub交付说明](agent/publish/README.md)；镜像下载见 [Releases](https://github.com/zhpowd-lab/open_logic/releases)。本版为实验预览，实物接点差异尚未采到。

独立入口：**http://127.0.0.1:8102/**。当前电脑服务已连接网口2的装置 `192.168.2.100:8102`，CPU3裸核与实时监视保持运行。装置模式入口为 `app/logic-analyzer/start-device.cmd`；固定图案入口为 `start.cmd`。已有8102实例时直接打开网页，不重复启动。Node.js 18及以上，无需npm install；本次使用v24.15.0。

提供16路阶梯波形、边沿触发、游标、横向缩放和平移，支持固定图案、文件和CPU3装置源。顶部实时监视独立于保留波形：CPU3空闲期约1kHz读当前值，网页200ms更新，YX1～YX16对应D0～D15，原始0/1不倒相。暂停监视仅冻结网页；波形运行/停止/单次也只控制显示与搜索，明确点击“新建装置采集”才发一次ARM并替换装置旧段。最多1秒/百万点/2MB，满深度保留首段，不循环覆盖。

**现场遥信正确性尚未通过：用户确认YX11、YX12、YX13中一路接点不同，但LBC和启动时的一次GPIO输入对照均为0xFFFF。** 网页与装置原码一致，仍需核对接点至缓冲器和CPU输入之间的实际电平。

## 固定图案回放

以下是本机测试模式。当前用户对照接点时保持装置模式运行，不切换8102的数据源。装置模式启动命令为 `node.exe server.mjs --device http://192.168.2.100:8102`。

```powershell
Set-Location F:\DDD\codeX\open_logic\app\logic-analyzer
node.exe server.mjs
```

浏览器打开 http://127.0.0.1:8102/。默认已载入 1,000,000 点 / 2,000,000 字节 / 1 µs 周期的固定测试图案，打开时保持显示停止。

1. 点击“测试缺口”，查看 D0 上 500.248～500.252 ms 的 4 µs 缺口。
2. 选择 D0、下降沿、搜索起点 500240，点击“单次”：在索引 500248 触发后冻结，触发点位于窗口中部。
3. 选择 A/B 后点击波形放置游标，或在“精确定位索引”填写 500248 / 500252。对应原码分别为 `0x510C` / `0x510F`，时间差 4 µs。
4. “运行”按源采样周期推进本机回放；“停止”只冻结显示，“运行”继续原进度。“运行时启用边沿触发”允许在回放过程中触发并冻结。
5. 到满深度就停止，不自动循环。“从头回放”明确回到同一保留段的起点，之后再点“运行”。
6. 滚轮横向缩放，手形工具拖动平移；也可用工具栏按钮、方向键和底部概览/位置滑块。整段视图只聚合绘图，触发和游标均使用原始样本。

“单次”在已载入的整段数据中搜索，不需要先播放到该位置。选 D15、双边沿可验证“未触发 · 已停止”；D15 在测试图案中恒为 0。

## 本地文件

可以在页面选取 `.u16` / `.bin` 与可选 JSON；文件只在本机浏览器读取。也可用服务端文件回放：

```powershell
node.exe server.mjs --file capture.u16 --meta capture.json
```

文件长度必须为非零偶数。一条样本一个小端 uint16，bit0=D0，bit15=D15。旧工程的 **256 字节共享记录不能直接作为本格式导入**。

JSON 格式、unknown 规则、丢样和深度口径见 `app/logic-analyzer/FORMAT.md`。

## 当前验收

Node解析/服务测试 **19/19**；本机图案桌面1440×1080、窄屏390×844、明暗主题浏览器验收 **36/36**。真实当前值监视浏览器 **12/12**，装置服务软件源浏览器 **19/19**；Linux服务 **5/5**，C总线/状态机ASan/UBSan检查通过。真实监视证明网页与装置返回值一致，**没有证明实际接点变位成功**。CPU3固定图案百万点与缺口验证通过，属于裸核测试源，不是实物输入。

验证命令与原始结果保存在 `agent/验收与复现.md`、`agent/verification/`；截图在 `agent/output/playwright/`。

**1 MHz是读取锁存器的目标速率，不代表开入光耦能传递MHz级边沿。** 实测既有百万点完成段，也有318899点后超期停采段，尚不能称长期稳定。时间轴按名义周期，实测读入口间隔另行报告，不是逐点RD硬件时标。8098、8099、6011与旧waveform/server.js保持独立，电脑仍只监听127.0.0.1:8102。未引入PulseView或新的绘图库；485/UART、CAN等已规划，尚未实现协议解码。未安装开机自启，断电/重启后需核对状态并显式启动。
