## 禁止裸立即数

次数、时限、时钟拍、引脚号、寄存器值和协议字段使用有名字的常量，枚举优先，其次const，宏最后。名字写出含义和单位。需要由汇编、链接预处理共用，或ioctl等工具链语法要求时保留宏；不为统一风格重写已验证布局。无符号常量加U，接口宽度使用stdint.h的固定类型。

```c
/* 24 MHz 计数。100 µs，只给启动发布留空，不是采样周期。 */
enum {
    L16_START_GAP_TICKS = 2400U,
    L16_PRIME_READS = 16U
};

due = l16_ticks() + L16_START_GAP_TICKS;
for (i = 0; i < L16_PRIME_READS && !shutdown_requested; i++)
```

不要写成 `+ 2400U` 或 `i < 16`。由已有常量算出的值继续用该常量，不把结果抄成新的数字。循环初值和结束判断使用有名字的常量，0和1按用户最新规则可以保留。函数约不超过100行、只做一件事；返回错误必须检查，一行一条语句；中文注释说明原因和约束。
